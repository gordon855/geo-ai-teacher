# 教师与学生使用说明

本说明针对独立演示实例；账号均为虚构账号。首次进入前按 INSTALL.md 启动。
默认地址 http://localhost:3000。

## 教师

1. 进入 /teacher/login，使用 demo_teacher 和本地 .env 的初始教师密码。
   首次登录按页面要求设置至少 10 位、包含字母和数字的新密码。
2. 进入教师工作台，确认当前班级为 GeoAI Demo Class、三名 Demo 学生。
   通过导航查看课程、名单、成绩、考勤、任务和练习。新建/导入操作只使用虚构信息。
3. 进入课堂 PPT 功能，上传自行拥有授权的 .pptx；旧 .ppt 不适用。
   目录管理与“当前课件”是两回事，上传到目录后按界面选择用于课堂的课件。
   学生只读取当前课件；更新后页面提示约 15 秒自动同步，也可刷新确认。
4. 学生练习、作业和课堂任务产生的记录可在相关管理面板查看。
   本次真实测过成绩、考勤和提问写入；完整作业评价流程仍须现场试用。
5. 名单导入对新用户产生临时密码表。现有代码不提供已验收的单个/批量重置
   密码工作流；不要把重新导入同名学生当作密码恢复操作。
6. LiteAvatar 启动/配置入口仍保留。必须另行准备合法模型、安装环境和网关，
   本候选版不包含完整权重或一键安装 ZIP，不能视为已通过数字人设备验收。

## 学生

1. 进入 /student/login，使用 demo_student_1、demo_student_2 或 demo_student_3。
   初始学生密码在 .env；首次登录必须设置自己的新密码。
2. “课堂交互PPT”显示教师当前课件，可翻页、缩放、选择英文查看语境说明。
   没有模型 Key 时不保证生成式翻译；数据演示不等于完整教材。
3. 使用练习、章节测试、作业和情境任务入口，按页面完成任务。
   练习进度会保存到数据库；已验证不同学生不能看到他人的练习记录。
4. “学习档案”不等于持久化自由笔记。独立电子笔记、浏览历史及语境翻译历史
   未被确认实现，不要把页面临时状态当成永久保存。
5. 操作结束点击“退出”；重新登录使用已修改的密码。学生无法进入教师工作台。

本次验收已更改教师和学生 1 密码，新值只保存在忽略的
.audit/browser-credentials.env；这是本地测试交接信息，不属于公开发行内容。
