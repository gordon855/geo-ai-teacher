# 数字教师小规模对比方案

本包提供可执行的试验工具和统一题本；尚无你的真实三平台测量结果，不给虚构排名。20条题目是测绘基准问答，不冒充教材逐字摘录或正式考试题。

## 统一条件
同一授权人物、近似裁切/分辨率/光照/背景；尽可能同一TTS或输入音频。无法统一时分组标记，不能把音色或资产差异归因于渲染器。LiveAvatar、LiteAvatar、LAM资产不能直接通用。固定答案模式与课程自由问答模式分开统计；冷启动与热会话、中文与英文、国内网络类型也分开。

先每平台20次，中英文各10题作为筛选；完整覆盖20题×2语言×3平台=120次。资源允许时每条件重复3次，共360次。失败样本保留，不从成功率分母删除。首轮只开一个会话，避免扩班并发产生无效费用。

| 指标 | 记录方式及边界 |
|---|---|
| 口型 | 同参考音频/文本，录屏人工1–5分：1严重错位，2频繁错位，3基本同步，4少量可见偏差，5自然稳定；至少两名评审独立评分更可靠 |
| 术语发音 | 按题本terms逐项检查，记录错误数/检查总数；GNSS、RTK等缩写事先确定读法；TTS不同须单独注明 |
| 首次响应 | T0=停止提问，T1=首次有意义语音，T2=首次说话画面；记录T1−T0和T2−T0毫秒。连接耗时与首声不同 |
| 打断 | T0=点击打断或开始打断语音，T1=旧回答停止；分别测按钮与语音，不能混算 |
| 国内访问 | 校园网、手机热点各一次；城市、日期、是否代理、ICE失败/重连/卡顿写明。国外服务器测试不能替代此项 |
| 实际费用 | 记录账单增量、币种、时长、GPU闲置、TTS/ASR/LLM、流量/TURN；估算与实际账单分开，未知留空 |

评分时可以增加“教师讲解可理解程度”观察项，但不要把默认样例形象比你的定制照片更自然等主观判断当成结论。

## 费用核算
托管套餐的额度分摊只用于估算，不等于本次支付额。自部署总费用=GPU开机时长费用+磁盘/带宽+TURN+ASR/TTS/LLM。单次费用从账单或用量日志核对；没有账单填写“估算分摊”或“未核实”，不能填0。

LiveAvatar官方FAQ区分Lite/Full的credits消耗。你旧截图约19美元/200credits不能自动视为现行套餐；在账户核对有效套餐、剩余额度、会话上限和是否自定义头像。不要为测试直接升级全年订阅。

参考：https://help.heygen.com/en/articles/12758866-liveavatar-faq 、https://www.liveavatar.com/ 。本包不代购。

## 输出与判断
每个成功条件汇总首声中位数、首次画面中位数、打断中位数、口型均分、术语错误率；另报全部尝试数和成功率。只有同时具备相同形象条件、相同语言/模式/网络/音色才适合直接比较。

教师端试验台可导出CSV。运行 `python3 scripts/v21-1-summarize-trials.py avatar-trials.csv` 获取分条件汇总；费用按币种和实际/估算分别统计。测试证据填本地录屏文件名即可，不上传学生身份或私人音频到公开仓库。

通过门槛建议（待你试验后调整）：首声中位数不超过3秒、口型至少4/5、关键术语错误率不超过5%、手动打断1秒内、校园网与热点均可连接。以上是试验目标，不是实测承诺。若达不到则先改语音/网络/模型配置，不投入全班。
