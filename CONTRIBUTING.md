# Contributing

Work from the 21.7 release candidate. Keep 21.8 proposals in ROADMAP.md until
implemented and verified. Describe the problem, behavior change and checks in
each pull request. Run npm ci, typecheck, lint, test and build. Use fictional
fixtures only. Do not contribute classroom records, credentials, model weights
or copied textbook/PPT excerpts without explicit redistribution permission.
Follow AGENTS.md and the installed Next.js documentation. Report security
issues privately using SECURITY.md. Project-owned work is licensed under
Apache-2.0 (see LICENSE and NOTICE). Submit only contributions you have the
right to license under Apache-2.0, identify third-party sources and retain their
notices. AI assistance does not replace provenance review. Public repository
publication remains a separate maintainer decision.
