# Security

Do not post secrets, student records or exploit details in public issues.
After repository publication, use GitHub private vulnerability reporting if
enabled; otherwise request a private reporting channel from the maintainer
without including sensitive details. No monitored security mailbox is claimed.

Keep .env, .data, backups, logs and .private-originals outside Git and images.
Use generated credentials, HTTPS for remote deployments, and least privilege.
Rotate any exposed credential; deleting the current file does not remove Git
history. Do not rewrite remote history without the owner's approval.
The automated scanner is a limited pattern check, not a guarantee of privacy.
